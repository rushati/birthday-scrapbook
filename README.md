# Birthday Scrapbook Website

A responsive scrapbook-style birthday website built using HTML and CSS and deployed via GitHub Pages.

**Live site:**
[https://rushati.github.io/birthday-scrapbook/](https://rushati.github.io/birthday-scrapbook/)

## Overview

This project is a static website designed as a digital birthday scrapbook. It combines a simple responsive layout, CSS animations, a photo gallery, and a music playlist embed to create a lightweight, mobile-friendly web experience.

The project demonstrates basic front-end development and static site deployment.
## Features
* Responsive layout for mobile and desktop
* CSS-based background animations
* Image gallery (polaroid layout)
* Embedded Spotify playlist
* Static hosting using GitHub Pages

## Technology Stack

* HTML5
* CSS3
* Git & GitHub
* GitHub Pages (deployment)
* 
## Running the Project Locally

Clone the repository and open the main file in a browser.

```bash
git clone https://github.com/rushati/birthday-scrapbook.git
cd birthday-scrapbook
```

Open `index.html` in your browser.

## Deployment

This project is deployed using **GitHub Pages**.

```
https://<username>.github.io/<repository-name>/
```
